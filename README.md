 A comprehensive Windows desktop application built to streamline daily pet shop operations. This system manages inventory, handles customer transactions, and tracks daily sales seamlessly. 

## 🚀 Tech Stack
* **Language:** C#
* **Framework:** .NET / Windows Forms (WinForms)
* **Database:** Microsoft SQL Server
* **Architecture:** Object-Oriented Programming (OOP)

## ✨ Key Features
* **Inventory Management:** Track pet and product stock levels with automated deductions.
* **Point of Sale (POS):** Cashier interface to safely process transactions.
* **User Role Management:** Secure login system with role-based permissions.
* **Sales Tracking:** Automated calculation of daily revenue.
